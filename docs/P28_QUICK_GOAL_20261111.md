# P28 — No-JSON, single-command verified quick CPU analysis (2026-11-11 KST)

## Design comparison

- A: generate ephemeral JSON files in the customer's source folder or use a model to invent commands. Easy adaptation but risk of unintended source writes, temporary-file races and prompt-injection-driven execution.
- B: translate **explicit CLI flags** into existing validated P19/P20/P22 goal objects entirely in memory; reuse their read-only CPU solvers and independent receipt guards. Selected for zero user data writes, no model/API fees and no duplicate math engines.

## Examples

```powershell
python -m eai quick-goal --kind csv_relationships --root examples --source sample_relationships.csv --columns ads sales refunds --json
python -m eai quick-goal --kind csv_robust_outliers --root examples --source sample_robust_metrics.csv --columns revenue --threshold 3 --json
python -m eai quick-goal --kind local_evidence_search --root examples --sources sample_evidence_notes.md sample_evidence_policy.txt --terms risk mitigation --json
```

All source paths are explicitly named inside the selected root and pass the existing strict validators, SHA-based read-only source checks and independent receipt guards. No goal JSON document is written, and no model is contacted. The text search default hides document excerpts, enabling them only with explicit `--include-snippets` (local terminal only). Real user file content and trustworthiness are never established by this tool; correlations do not prove causation, MAD flags are candidates, and keyword matches are not document truth.
